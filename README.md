# Modelado de Accesibilidad Topográfica mediante Grafos y Costos AsimétricosEste repositorio contiene el código fuente y la metodología espacial desarrollada para la investigación "Modelado de Accesibilidad en Terrenos Montañosos", enfocada en los municipios de Pespire y San Antonio de Flores, Honduras.## Justificación MatemáticaEl modelo sustituye las métricas de distancia euclidiana por una matriz de impedancia asimétrica. El costo temporal $W(u,v)$ de cada arista se calcula integrando la función cinemática de Tobler y fricción superficial:`W(u,v) = d_s(u,v) * [Φ(s) * 0.06] * f(u,v)`## Requisitos y Configuración1. Clonar el repositorio.2. Instalar las dependencias: `pip install -r requirements.txt`3. Descargar el Modelo Digital de Elevación (SRTM 1-Arc Second) de la NASA y colocar el archivo `.tif` en la raíz del proyecto.## Arquitectura del Proyecto (Pipeline)El procesamiento se divide en 6 módulos secuenciales:* **01_extraccion_osm.py**: Descarga topológica de la red vial vía OSMnx.* **02_modelo_tridimensional.py**: Intersección vectorial-raster y reproyección a UTM Zona 16N.* **03_calculo_impedancia.py**: Aplicación del tensor cinemático de Tobler.* **04_analisis_estadistico.py**: Validación y exportación de la matriz de adyacencia.* **05_optimizacion_rutas.py**: Ejecución estocástica de Dijkstra (rutas de menor costo).* **06_isocronas_cobertura.py**: Modelado macro de aislamiento territorial mediante isocronas temporales.
